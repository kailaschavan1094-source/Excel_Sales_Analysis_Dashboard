
# 📊 Excel Sales Analysis Dashboard

## 📌 Project Overview
This project analyzes Superstore Sales data using Microsoft Excel. The dashboard provides interactive insights into sales performance, profit, quantity, regions, categories, cities, and states using Pivot Tables, Pivot Charts, Slicers, and KPI Cards.

---

## 🛠 Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Pivot Charts
- Slicers
- Conditional Formatting
- Data Cleaning
- Dashboard Design

---

## 📈 Dashboard Features
- Total Sales KPI
- Total Profit KPI
- Total Quantity KPI
- Total Sub-Category KPI
- Top 10 City by Profit
- Sales by Region
- Category-wise Profit
- Top 10 State by Sales
- Interactive Slicers (Category, Region, Segment, Ship Mode)

---

## 🔍 Key Insights

- West Region generated the highest sales.
- Technology is the most profitable category.
- Office Supplies contributed the second-highest profit.
- Furniture generated the lowest profit among all categories.
- New York City recorded the highest profit.
- California and New York are the top-performing states by sales.
- Interactive slicers allow users to filter data by Category, Region, Segment, and Ship Mode.
